From College Algebra to Autonomous Robots

A complete 4-year, full-time Computer Engineering curriculum for the absolute beginner.

This roadmap assumes exactly two starting conditions: you can do College Algebra-level mathematics, and you have never written a line of code. Across eight sequenced semesters it systematically builds you up through Calculus 3 with Analytic Geometry, professional software engineering in Python and C++, digital logic and x86 microprocessor architecture, and finally the full autonomous-robotics stack — kinematics, perception, motion planning, and independent safety governors that stand between an AI planner and real hardware actuators. General-education requirements (composition, humanities, social sciences) are intentionally omitted so the technical spine stays in focus.

Deploy This Page Free on GitHub Pages

This entire platform is one self-contained index.html file — no build tools, no server, no framework install. Follow these steps and it will be live on the public internet in under five minutes.

  1. 1

    Sign in at github.com, click the + icon in the top-right corner, and choose New repository. Name it (for example my-engineering-roadmap), set visibility to Public, and click Create repository.

  2. 2

    Save this file to your computer with the exact filename index.html. In your new repository, click uploading an existing file (or Add file → Upload files), drop index.html in, and click Commit changes to the main branch.

  3. 3

    Open the repository's Settings tab, then choose Pages in the left sidebar. Under Build and deployment → Source, select Deploy from a branch.

  4. 4

    In the Branch dropdown, pick main, keep the folder set to / (root), and click Save.

  5. 5

    Wait roughly one minute, then refresh the Pages settings screen. GitHub displays your live URL in the form https://<username>.github.io/<repo-name>/. Open it — your curriculum platform is now launched and shareable. Every future commit to main redeploys automatically.

Note on progress data: the completion checklist is saved per-browser via localStorage, so your checkmarks persist on your own device but are not shared between visitors — every learner who opens your published page gets their own private progress tracker.
